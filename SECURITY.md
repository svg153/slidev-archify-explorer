# Security policy

## Supported versions

Only the latest release is supported with security fixes.

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues. Use [GitHub's private vulnerability reporting](https://github.com/svg153/slidev-archify-explorer/security/advisories/new) or contact the repository owner privately through GitHub. Include steps to reproduce and the affected version. We will acknowledge reports as soon as practical and coordinate disclosure with the reporter.
