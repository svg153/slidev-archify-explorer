# Contributing

Thanks for helping improve Slidev Archify Explorer.

## Development

```sh
npm ci
npm run dev
npm run build
```

Keep the demo focused on one Archify diagram. When changing the component, verify the live dialog and confirm PDF export still contains the static SVG without the interactive controls.

## Pull requests

- Open an issue first for large changes.
- Use a Conventional Commit title and commit messages, e.g. `fix: keep the dialog inside the viewport`.
- Include a screenshot when changing the presentation or component appearance.
- Keep changes accessible, keyboard-operable, and compatible with Slidev's PDF exporter.
- Ensure `npm run build` passes before requesting review.

By contributing, you agree that your contributions are offered under the repository's MIT license.
