Get started

Add it to a deck in a minute.

Install the addon, declare it in your Slidev frontmatter, then point the component at files in your deck’s public folder.

1

Install the package

npm install --save-dev slidev-addon-archify-explorer
2

Register the addon

addons:
  - slidev-addon-archify-explorer
3

Use it in a slide

<ArchifyExplorer
  preview="diagrams/system.svg"
  src="diagrams/system.html"
  title="System architecture"
  alt="System architecture diagram"
/>
↗

Your files stay yours.

Put the standalone Archify HTML and its SVG preview under public/. The component respects Slidev’s base URL and never needs an external diagram service.

Component API

A few props. No framework of its own.

Pass local files from your deck’s public directory. The default slot lets you provide a custom preview or layout.

Prop / slotTypeDefaultPurpose
srcstring · required—Path to the standalone Archify HTML viewer.
titlestring · required—Accessible name for the explorer dialog.
previewstring—Optional SVG shown as the clickable slide preview.
altstringtitleAlternative text for the preview image.
buttonLabelstringExplore diagramLocalized action text shown on the preview.
closeLabelstringCloseLocalized label for the dialog close button.
default slotVue template—Custom preview content; retained in print mode.
